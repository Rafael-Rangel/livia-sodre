# Lívia Sodré — Estética Avançada

Site premium com landing cinematográfica, catálogo de serviços, agendamento nativo e dashboard administrativo.

## Stack

- Next.js 16 + TypeScript + Tailwind
- GSAP + ScrollTrigger + @gsap/react
- Three.js (atmosfera no hero)
- Framer Motion
- Auth JWT (jose) no dashboard

## Desenvolvimento

```bash
npm install
npm run dev
```

Abra [http://localhost:3000](http://localhost:3000).

Dashboard: `/dashboard/login` — senha padrão `livia2026`.
